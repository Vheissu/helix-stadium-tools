## Changes and verification

Perform adds Stomp A, Stomp B and Snapshots views. Snapshots open by default, and the main editor has a direct Snapshots shortcut. Stomp views display assignments and custom labels; triggering them still uses the Stadium footswitches.

List layout adds Pick up, Drop here and Cancel move with spoken feedback and focus requests. Parameter values retain native adjustable actions, increase/decrease buttons and exact entry. Sync, Refresh, Options and parameter Help have visible text. Offline preview uses the same block-movement controls.

All 112 mobile tests, TypeScript checking and production JavaScript exports passed. ESLint had zero errors and two existing hook-dependency warnings. [CI passed](https://github.com/Vheissu/helix-stadium-tools/actions/runs/39415493664), and both signed cloud builds completed. Required song-upload credentials were prepared on both builders.

The iPhone simulator checks covered native value adjustment, moving a block while retaining its parameter value, cancellation and invalidating a pending move after a path change. A physical iPhone VoiceOver session, full large-text traversal and connected spare-preset testing remain tester checks. See [accessibility verification](ACCESSIBILITY.md) for the exact scope.

Release metadata, tester notes, store confirmations and artifact checks are saved under `.codex-artifacts/oct20-release/`.
