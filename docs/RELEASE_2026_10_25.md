# HELYON testing release, 25 October 2026

HELYON 1.0.0 was uploaded from the signed production builds made from source
commit `48e407c`: iOS build **15** and Android build **16**. Both uploads
completed successfully. The [build report](BUILD_2026_10_25.md) records the
dependency checks and artifact verification.

## TestFlight

iOS **1.0.0 (15)** is **Testing** for all **76 registered testers**: 75 external
and one internal. App Store Connect confirms that processing is valid, beta
review is approved, and both internal and external testing are active.

Build 15 is assigned to all three existing groups. A comparison with the app's
complete tester list found **76 covered testers and zero uncovered testers**.
Automatic notifications are enabled. Existing tester memberships and earlier
builds are retained. This was verified at **5:19 pm Brisbane time**.
