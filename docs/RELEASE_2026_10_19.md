Version **1.0.0 (7)** was published to the internal track at 3:48 pm Brisbane time. Play reported one non-blocking warning: the new-install download grew by 6.53 MB to 19.2 MB. There were no release-blocking errors or reductions in supported devices.

The first attempt, build 6, failed before upload because Stadium transfer used `bcprov-jdk18on` while the TCP library used `bcprov-jdk15to18`. The fix uses the same Android artifact family and aligns the provider, PKIX and utility components at 1.86. The duplicate-class check, native transfer compilation and full local `assembleRelease` passed before the cloud retry. Build 6 was never uploaded to Play.

## Included changes and checks

This release includes preset creation in empty User slots, confirmed preset saving, the redesigned Focus surface and prepared WAV song uploads with Showcase playback controls. Song uploads require 48 kHz/16-bit PCM WAV tracks and a microSD card in the Stadium.

The release checks passed 98 JavaScript tests and TypeScript checking. ESLint reported no errors and two existing hook-dependency warnings. Both signed cloud builds completed; Android also passed a full local release build after its dependency fix.

EAS production uses a project-scoped secret file for the official editor's transfer credential. The generated local credential file is excluded from the build source archive. The builder's required post-install hook confirmed that song-upload credentials were prepared.

Screenshots, build metadata and read-only track verification are in `.codex-artifacts/oct19-release/`. Android hardware song-upload testing and continuous Focus dragging remain tester checks; successful builds are not a claim that those physical-device paths were verified.

The build 3 tester notes cover Focus dragging and named tones, preset creation and save/reload, prepared WAV Showcase uploads and playback, and useful device details for bug reports. The existing automatic tester-notification setting was retained. Confirmation is saved as `.codex-artifacts/oct19-release/ios-builds-2-and-3-testing.png`.
