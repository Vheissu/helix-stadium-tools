# HELYON icons

These 24 category and connection icons were generated on 21 October 2026
with the built-in image generation tool from text descriptions of musical
functions and generic equipment. No reference images were supplied. The
complete prompts are recorded in `prompts.json`.

The PNGs are 192 × 192 with transparent backgrounds and black artwork.
React Native callers apply `tintColor` for the category or interface colour.
The generated images were resized with macOS `sips`; their shapes were not
traced from the previous extracted icons.

These files replace the desktop-editor artwork in the app source. Existing
store builds and screenshots still need replacement. This change does not
establish permission for the bundled model data, product names, or hardware
control, and does not resolve Apple's 5.2.1 rejection by itself.
