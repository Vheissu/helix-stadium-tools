# USB and Factory fixes

Source commit: `756a905838e89ca7f35d45776a5a640f0bb2d4e8`.

## Changes

- Android USB address discovery allows 65 seconds before timing out, followed
  by a separate 20-second limit for each editor connection. The previous
  combined 20-second limit could reject a working connection before the next
  periodic address announcement. Errors now identify which stage failed.
- Returning from Android's USB permission dialog rechecks access, including
  when a dismissed dialog fails to deliver its response. Earlier attempts
  cannot complete a newer permission request.
- The connection screen allows cancellation and clears earlier error messages
  when starting a new attempt.
- Factory browsing uses the working factory-library request and reads the
  original preset references, preserving names, positions and locks. This
  also repairs the Factory source in the setlist picker.

## Validation

- 288 mobile tests passed. TypeScript and production exports passed for both
  platforms. ESLint reported zero errors and two existing hook warnings.
- 12 Android USB unit tests passed, including retry after a dismissed dialog
  without unplugging. The local Android build passed.
- Six packet-stack scenarios passed with address and undefined-behaviour
  sanitizers. These cover normal connection, lost packets, solicited address
  announcements, a 60-second announcement after three lost requests, and
  separate failures for missing announcements and an unanswered connection.
  Successful cases transfer 10 KB on each of two connections across two
  reconnect cycles. The old code fails the delayed-announcement case with
  the error shown in the owner's screenshot.
- Read-only device queries returned all 66 Factory presets with valid
  references at positions 0–65. The active preset remained unchanged.
- Cancellation was exercised in Android Emulator. The final Factory UI check
  could not finish after the Stadium became unreachable from the test host.

Physical Galaxy S25 Ultra USB reliability still requires a retest with the new
build. The timing test reproduces a defect; it does not establish that this
was the only cause of the owner's intermittent connection failure.
