# Store screenshots

These six JPEGs are the selected iOS App Store screenshots for build 8.
They combine actual native app captures with HTML typography and framing.

- iPhone: 1320 × 2868, three images.
- iPad portrait: 2064 × 2752, two images.
- iPad landscape: 2752 × 2064, one image.

Serve `source/` locally and open `index.html?card=iphone-01` (or the other
filename stems). Set the browser viewport to the corresponding dimensions
before capturing. The landscape raw capture is rotated through CSS to match
its native orientation. `manifest.json` records the final image hashes.

The screenshots show sample data in the app's offline preview. No interface
elements or hardware imagery were generated for them.
